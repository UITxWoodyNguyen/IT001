
# 📘 README.md – Môn học IT002

## 1️⃣ Giới thiệu

Repository này được xây dựng nhằm lưu trữ toàn bộ mã nguồn, bài tập, và tài liệu liên quan đến môn học IT002. Đây là nguồn tham khảo hữu ích cho sinh viên đang học môn này, người tự học, hoặc bất kỳ ai muốn ôn tập, củng cố kiến thức lập trình.

---

## 2️⃣ Nội dung môn học

Các chủ đề/chương đã học:
- Chương 1: Giới thiệu lập trình hướng đối tượng
- Chương 2: Tính đóng gói (Encapsulation)
- Chương 3: Kế thừa (Inheritance)
- Chương 4: Tính đa hình (Polymorphism)
- Chương 5: Bảo vệ truy cập (Access Control)
- Chương 6: Bài tập tổng hợp & ứng dụng

## 3️⃣ Cấu trúc thư mục

```

│

├── LAB/                     # Thư mục chứa bài lab thực hành
```

- **README.md**: Hướng dẫn sử dụng, thông tin môn học.

## 4️⃣ Mô tả bài tập

- Bài tập được phân chia theo tuần/chương, mỗi bài giải quyết một vấn đề cụ thể về lập trình hướng đối tượng.
- Ví dụ:
	- `intro-encapsulation.cpp`: Minh họa tính đóng gói – mức độ dễ.
	- `intro-inheritance.cpp`: Ví dụ về kế thừa – mức độ trung bình.
	- Bài lab: Thực hành tổng hợp, áp dụng kiến thức – mức độ khó.

## 5️⃣ Hướng dẫn chạy code

- **Compile**: Sử dụng trình biên dịch C++ (g++ hoặc tương đương).
	```
	g++ ten_file.cpp -o ten_file
	```
- **Run**:
	```
	./ten_file
	```
- **Ví dụ input/output**: Được ghi chú trong từng file bài tập (nếu có).
